# 報酬改定ナビ

社会福祉法人豊徳会 AI業務効率化PT 制作

障害福祉サービス 令和6年度報酬改定情報を、現場職員が素早く確認できる Web システム。

**公開URL**: https://kanda-houtokukai.github.io/houshu-navi/

---

## 概要

報酬改定の告示・Q&A・通知を横断的に検索し、自事業所での算定可能性を診断できるナビゲーションシステム。

### 対象サービス(4種)

豊徳会の主軸事業をカバー:

- 障害者支援施設(入所)
- 生活介護
- 児童発達支援・放課後等デイサービス
- 就労継続支援B型

### スタンス

- 個人情報は扱わない(内部知識ベースに特化)
- 「最終判断は告示原本・自治体照会」を常に明示
- 単位数等の数値情報は「要確認」と表記して誤情報リスクを回避

---

## 現在の機能(2026-05-16時点)

### 1. ホーム(ダッシュボード)

- Stripe 風メッシュグラデーション(6色)
- ヒーロー:「報酬改定の答えを すぐ、そこに。」
- 主要機能への導線カード

### 2. 加算を探す

サービス別に加算・減算を一覧表示。

- 全 **29件**(加算 + 減算)
- サービスフィルター(全部 / 入所 / 生活介護 / 児発放デイ / 就労B / 共通)
- 「生活介護」を選ぶと共通加算も含めて10件表示される拡張マッチ

### 3. キーワード検索(統合横断検索)

加算と Q&A を横断検索。

- 検索対象 **175件分**(加算29件 + Q&A 146件)
- 加算名・概要・要件・備考・Q&A の質問と回答を全文検索
- [加算] [減算] [Q&A] のタイプ別バッジで結果表示
- サービスフィルター適用可

### 4. Q&A集

厚労省 Q&A 全 8巻のテキスト全文を収録。

| Vol. | 件数 |
|------|------|
| Vol.1 | 86 |
| Vol.2 | 25 |
| Vol.3 | 14 |
| Vol.4 | 7 |
| Vol.5 | 8 |
| Vol.6 | 2 |
| Vol.7 | 1 |
| Vol.8 | 3 |
| **合計** | **146** |

※ Vol.6〜8 が少ないのは単一トピック特化のため(取り漏れではない)

### 5. 算定診断フロー(3ステップ)

「うちは算定できる?」を3問で診断。

- Step1: サービス選択(単一)
- Step2: 利用者特性(複数選択)
- Step3: 体制・職員配置(複数選択)
- 結果: 算定可能性高 / 要件確認 / 減算リスク で分類表示
- ページ再アクセス時は自動リセット

## 技術構成

- **構成**: 単一HTML(SPA)+ JSONデータ
- **依存**: なし(ピュア HTML / CSS / JavaScript)
- **ホスティング**: GitHub Pages
- **動作環境**: モダンブラウザ(Safari / Chrome / Edge)
- **ローカル動作**: file:// 直接開きでも fetch が動作(Safari 実機確認済み)

### 制約

- localStorage / sessionStorage は使用しない(状態はメモリ内のみ)
- 単位数等は「要確認」表記で固定(誤情報リスク回避)
